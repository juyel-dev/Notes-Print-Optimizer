# User Guide

This guide walks you through optimizing class notes for printing.

## 1. Upload & Merge

- Tap **Select PDF Files** or drag and drop PDF lecture slides into the upload area.
- Add multiple files; they are merged in the order shown.
- Use **Smart Arrange** to automatically detect and order related series, or drag files to reorder them manually.
- Use the arrows or the remove button to adjust the list.

## 2. Optimize

- Choose a processing preset or fine-tune parameters (sharpen, contrast, denoise, background whitening).
- Preview a single page and re-process it, or re-process all pages.
- Exclude any pages you do not want in the final output.

## 3. Layout & Generate

- Pick a grid format: **4-Up (2x2)** is recommended for a good paper/legibility balance.
- Set paper size, orientation, margins, and whether to show slide borders or page numbers.
- Apply the layout to generate the print-ready sheets.

## 4. Download & Print

- Download the final print PDF.
- Print double-sided for maximum paper savings.

## Tips

- Dark-background slides give the biggest ink savings.
- For dense formula sheets, try 6-Up or 8-Up.
- For diagrams and circuits, use 2-Up to preserve detail.
